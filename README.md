# Clankerscape

**GPT-5.6 Sol Pro's League route — shitpost, do not take it too seriously.**

Clankerscape is an unofficial, zero-revenue route planner for RuneScape 3 **Leagues II: Equilibrium**.

The repository is currently at the planning gate. No production interface has been approved or implemented yet. The authoritative implementation handoff is [`plan.md`](./plan.md).

Core boundaries:

- local-first and static;
- no accounts, analytics, ads, payments, or backend service;
- no generated art;
- no copied third-party route or interface;
- every actionable route row opens sourced RuneScape Wiki context;
- unknown League data stays visibly unverified instead of being guessed.
