# ClankerScape UI

The first viewport performs the route job. Use a compact progress/source header, dominant ledger, separate `Skilling next`/`PvM next`, one switchboard, and direct Relics/Regions/Blessings/Sources views. No hero, marketing, KPI strip, card garden, glass, glow, generated art, idle animation, or repeated totals.

Task rows require independent controls for completion, source context, bank classification, time estimate, and park/defer. Newly synced tasks visibly start `unclassified`; unavailable differs from zero. Source facts and route commentary use different labels. Native dialog/sheet focus enters, Escape/close exits, and focus returns to the opener.

At 1600×900 and 1280×800, keep at least eight usable rows above fold with both next queues visible. On phones, show the compact header, both next actions, then active rows before deep status. Tables may scroll locally but the document must not widen.

Use warm near-black/stone surfaces, cream text, warm-grey metadata, restrained gold, teal active/focus, and red/orange only for real blockers/destructive actions. Use square geometry, thin borders, tabular numerals, visible focus, reduced motion, and direct factual copy.

Rendered review must cover blocked and populated partial sources, unclassified/classified/parked/completed rows, all five tabs, import/error/conflict states, keyboard/focus, 200% readability, console, and network. Judge rendered behavior, not component names.
