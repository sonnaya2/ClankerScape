# ClankerScape review

Return READY, READY WITH FOLLOW-UP, NOT READY, or BLOCKED. Critique defects, not people. A fabricated fact, illegal task, unsupported irreversible choice, broken source gate, data loss, inaccessible core action, leaked secret, or licence misrepresentation is a blocker.

## Source/data

Verify the live official frame, canonical Wiki page, 48,000 target, 50/175/300/450 gates, 1,152/109,380 totals, region sums, 20 relics, 24 Blessings, thresholds, three Blessing resets, and absence of an ordinary relic reset. Production rows require numeric unique IDs, valid point bands, revision/source metadata, and no Catalyst/testing records. Partial data must fail closed. Unreviewed rows must remain unclassified.

Check importer timeout/size limits, inert text extraction, duplicate/empty rejection, unchanged-source no-op, scheduled/manual workflow behavior, and snapshot licence attribution.

## Route/decisions

Verify legal dependencies before ranking; five banks plus unclassified intake; real skilling/PvM next actions; reserve reconciliation; P50/P90/switch/failure/supply costs; and 48,000 executable points. Region totals cannot choose regions.

Every relic tier must compare every option by remaining-route minutes. Tier 6 must compare Perkfection against every plausible missed Tier 1–5 relic, model 20% helpful-proc frequency only on affected throughput, and use `max(30 minutes, 3% remaining P50)` plus non-overlapping conservative ranges. No working favourites or unexplained synergy pass. Ordinary relics are never resettable without a new primary source.

Blessing review verifies both three-pick God segments, three epoch resets, erased history, repay-before-Dragon logic, and blocked True Equilibrium benchmarks while relic alignment conflicts with the engine.

## UI/runtime

Render partial/populated, completed, planned, spare, skipped, error, and conflict states at laptop, desktop, and phone widths. Check all four pages, the task details sheet, selected relics, expanded Tier 6 comparison, region estimates, selected Blessings, reset history, save menu, and storage failure.

Require the player task to dominate the first viewport; no document overflow; readable mobile-native layouts; keyboard focus restoration; reduced motion; and no console or page errors. Reject heroes, KPI gardens, switchboards, status rails, glass/glow/gradient chrome, internal model labels, repeated source controls, clipped desktop tables on phones, and other generic generated-dashboard structure. Run `clankerscape-bot-audit` before approval.

## Security/licensing/workflows

Reject credentials, private account/source material, arbitrary outbound domains, unsafe imports, unsanitised HTML, unnecessary dependencies/permissions, or automatic deployment without approval. Original CC0 material and imported CC BY-NC-SA Wiki text must be distinguished. Review the generated Pages artifact rather than assuming the workflow stages only intended files.

State exact commands, observed evidence, unverified coverage, and required repairs. Never write only `looks good`.
