## Source policy

Primary:

1. current official Jagex Equilibrium announcements/rules;
2. canonical RuneScape Wiki Equilibrium pages;
3. reviewed repository records with provenance.

Conditional only:

- Equilibrium combat engine results when compatible and source-clean;
- RS Analysis/PvME only for mechanics not resolved by stronger current sources.

Not used as route authority:

- Catalyst tasks;
- public user routes;
- Reddit/social posts/comments;
- copied layouts or code from other tools;
- passing tests or code comments that conflict with official text.

## Implementation result

- dependency-free static application;
- fail-closed numeric Wiki task importer;
- exact official total validation;
- all 20 relics and 24 Blessings represented;
- Perkfection/Rejuvenated break-even model with uncertainty;
- ordinary relic reset explicitly unavailable;
- three Blessing reset epochs;
- rendered blocked-source and populated-partial desktop/laptop/phone review;
- explicit unclassified intake and independent park control;
- no copied private code, screenshot, font, credential, generated art, or unrelated repository material.

## Audit corrections applied back to the skills

The project route/review skills were rewritten after the final audit to remove all working relic/region favourites and the old 8% rule. They now require all-option remaining-route comparisons, the `max(30 minutes, 3% remaining P50)` plus non-overlapping-range gate, explicit unclassified task intake, Wiki licence review, and populated-source rendering before readiness.
